# E17 — The first release (v0.1.0): the handover

The arc: the 2026-11-06 ask — release builds for Linux (amd64/arm64),
macOS (arm64) and Windows (amd64), GitHub workflows for the first
release with short notes, and an install script that also covers the
opencode wiring. D27 settles the distribution shape, D28 holds Windows.

              crates, rustc 1.98.1

              U87 — `.github/workflows/ci.yml` (fmt, clippy -D

              U91 (finding, fixed) — on Linux the shim's respawn

              i.e. `/proc/self/exe` = `<path> (deleted)`: every

              E8) — the Homebrew-on-Linux variant (the keg path

              on macOS the re-install lands a fresh inode, a tampered
              tarball fails the checksum, a pre-existing opencode
              entry is reported instead of printed. The formula
              passes `brew style` and `brew audit --strict`.
              `cargo test --workspace` in a Linux container
              (rust:1-trixie arm64, non-root, lsof + procps): 880

              failed there (census `[]`, shim exit 1). A manual

## Handover — 2026-11-08 (D29 packages; immutable releases)

Workspace:    main's history rewritten from d0c50f3 on (the release
              commits re-made so the public README never carried
              release/CI internals; those live in the maintainer's
              untracked README.ci.md) — origin/main still holds the
              pre-rewrite history until the force-push below
Landed:       D29 signed in-thread (.deb/.rpm via nfpm). U93 —
              `packaging/nfpm.yaml`, the maintainer scripts (SIGTERM
              every `/usr/bin/todo-mcp` daemon, found through /proc,
              on upgrade and removal, never on a fresh install), the
              DEP-5 copyright; a `packages` job in release.yml (nfpm
              2.48.0 pinned + sha256-verified, deb/rpm for
              amd64/arm64 from the tag's own musl tarballs — binary,
              README, licenses — apt and dnf smoke installs); the
              packages in SHA256SUMS; README, §13, decisions.md.
              Immutable releases (the repository setting): published
              assets and tags are frozen and a deleted release's tag
              name cannot be created again (measured; §13). The
              workflow refuses a tag with a published release up
              front and publishes draft → upload → publish, so a
              failed run leaves a draft a rerun finishes.
Measured:     the packages, built from release-built musl tarballs:
              install → upgrade (a rebuilt higher version) → remove
              with daemons in both argument orders on Debian trixie
              and trixie-slim, Ubuntu 20.04/24.04/26.04, Fedora, Rocky
              9 minimal, Alma 8 (amd64 and arm64; pkill absent on the
              slim/Fedora/EL images): every daemon ends on upgrade and
              on removal, a fresh install leaves them. The packages
              job ran green on GitHub (nfpm
              verified, 4 packages, apt + dnf smoke). lintian/rpmlint:
              only static-binary, no manpage, no distro changelog.
              Prerelease naming: VERSION=0.2.0-rc1 → files spelled
              `0.2.0~rc1-1`. At the rewrite's head: 880 tests,
              clippy/doc -D warnings, the release build's version line,
              actionlint, shellcheck, check-links.
