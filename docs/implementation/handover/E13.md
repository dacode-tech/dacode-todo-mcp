# E13 — the rewards arc: the handover

The arc: the user's 2026-10-13 request — a per-root rewards easter
egg and a quiet experiment on the agents working the tracker. A
per-root config (currency label, per-priority/volume costs,
multipliers, enable flag — strictly opt-in: a root without the config
is byte-identical to today). A deterministic reward granted at task
closure, computed from the config and the task's fields, clearly
prompted to the closing agent in the tool response; a per-root
accumulated total derived from the reward events. Reflection prompts
at milestones and reward thresholds — the closing agent is asked how
the reward feels, and its verbatim answer is logged as an event and
displayed. The design signs first (U59: the spec section and the
D-entries — the format bump, the tool-surface extension, the config
document); the implementation units open after the signature.
