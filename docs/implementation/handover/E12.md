# E12 — the per-epic pages arc: the handover

The arc: the user's 2026-10-12 go on U50 — per-epic pages in the live
view, shape (b) with lazy client-side navigation. The epic pages are
real server-rendered routes (`/repo/<slug>/epic/<number>`) for direct
URLs, bookmarks, no-JS and goldens; the page's script intercepts
sidebar epic clicks, fetches the epic page on demand, and swaps the
content region without a full page reload; the WS push re-fetches the
current view through the same fetch+swap mechanism. No new
dependencies — a hand-built script beside the existing click-detail
and WS scripts. The static progress output stays one snapshot
(serve-only scope). Three units: U52 (the render surface and its
golden), U53 (the routes and dispatch, protocol-tested), U54 (the
sidebar links and the lazy script — page.v1 moves, the diff called
out as the compatibility event).
