The first tagged release of `todo-mcp`, a deterministic task-graph MCP
server: markdown task boards become typed, queryable graphs (epics,
tasks, gates, findings, debt, decision dossiers, registered docs), and
"what is next in repo X under epic Y" becomes a protocol call.

## Install

```sh
curl -fsSL https://github.com/dacode-tech/dacode-todo-mcp/releases/latest/download/install.sh | sh
```

The script verifies the checksum, installs to `~/.local/bin`, and
prints the opencode `mcp` entry to add; it never edits your config.

Debian, Ubuntu:

```sh
curl -fLO https://github.com/dacode-tech/dacode-todo-mcp/releases/download/v0.1.0/todo-mcp_0.1.0-1_amd64.deb
sudo apt install ./todo-mcp_0.1.0-1_amd64.deb
```

Fedora, RHEL/Rocky/Alma 8+:

```sh
sudo dnf install https://github.com/dacode-tech/dacode-todo-mcp/releases/download/v0.1.0/todo-mcp-0.1.0-1.x86_64.rpm
```

ARM: `_arm64.deb` / `.aarch64.rpm`. The packages install
`/usr/bin/todo-mcp` with no dependencies, so one package per
architecture fits every release of its family. Upgrading one stops
running daemons and open sessions respawn them from the new binary;
removing one stops them for good. There is no apt/yum repository.

port is open as decision D28 — use WSL2 with the Linux build) and
Intel macOS (build from source with `cargo install --locked --git
https://github.com/dacode-tech/dacode-todo-mcp todo-mcp`).

## What is in it

- 27 MCP tools over stdio: the repo registry, epics, tasks with
  closure discipline (no closing without evidence), `blocks`/`relates`
  edges with write-time cycle checks, decision dossiers that gate work,
  registered docs, `next_task`/`next_items`/`status_summary`,
  `graph_show`, and `import_md` for five board dialects.
- One daemon per store root behind thin per-session shims: every
  session shares one writer, updates restart the daemon without
  restarting sessions.
- The CLI in the same binary: `progress` (static page + JSON),
  `serve` (the live view on 127.0.0.1), `refresh`, and the
  `dump`/`verify`/`repair` inspector.
- Store format version 2 under `~/.local/share/dacode-todo/`; a binary
  refuses a store newer than it understands.

Checksums: `SHA256SUMS`.
